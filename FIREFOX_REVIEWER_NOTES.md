# Firefox reviewer notes — changes since 1.4.0

This update can be reviewed by signing into a student account on a supported *.brightspace.com site and opening its home page. On the Dashboard, use Search or press s to search current-course content; arrow keys select a result, Enter opens it and Escape closes the dialog. In a course's Home or Modules view, use an item's three-dot menu to pin/unpin it; pinned items appear in a Pinned module at the top, including imported Ed/Gradescope entries when those integrations are enabled. Enable Tasks Panel in Dashboard Options to test completion updates and score display; the panel's three-dot menu beside + offers Three-Day View and all/10/5 task limits, while 24-Hour Clock is in Dashboard Options. Completing all tasks in a displayed period triggers course-colored confetti for five seconds; the effect respects reduced motion and remembers the latest celebrated period. The newly bundled extension/vendor/confetti.browser.js is unmodified canvas-confetti 1.9.3, with its ISC license alongside it; it runs locally without a worker or remote script loading. In Grades, test What-If edits on weighted categories, blank grades and dropped items: category totals and the overall estimate update locally and do not write grades back to Brightspace. The extension now also reads Brightspace's Grades page to identify Dropped! marks; toolbar diagnostics report drop-related field names and counts without grade names or scores. For optional integrations, use Account > Connected sites: Gradescope requires the reviewer's own Gradescope sign-in; Ed requires enabling Ed, granting access and supplying the reviewer's own Ed API token for the appropriate region. Check Ed now inspects the response structure of one completed/attempted lesson and a challenge's submissions through narrowly allowlisted, read-only background requests; this is diagnostic support, and Ed score importing is not yet implemented. The token is handled in the extension background and sent to Ed, not the Brightspace page. Supported Firefox versions and the data-collection declaration are unchanged from 1.4.0. Version 1.7.0 adds two Firefox permissions for the optional Reminders feature (Account > Reminders, off by default): alarms, used by the background script reminders-bg.js to schedule due-date reminders (no install-time warning), and notifications as an optional permission, requested only when the user turns Reminders on and never at install. On Firefox for Android, Reminders only shows a note because extension notifications are unavailable there. Version 1.7.0 also adds an optional Edfinity reader (Account > Edfinity or Connected sites, off by default): the optional host permission https://edfinity.com/* is requested with permissions.request only when the user turns it on. The background handler (message bsx-edfinity) accepts messages only from the extension itself (sender.id) and does read-only GETs to https://edfinity.com with credentials included, limited to the paths ^/registrations(\?[\w=&]*)?$, ^/registrations/[0-9a-f]{24}$ and ^/registrations/[0-9a-f]{24}/assignments$; there are no POSTs and no other hosts. A content script on https://edfinity.com/* (src/edfinity.js, document_idle) does nothing unless the reader is on; when on, it reads the page's inline JSON and the same two JSON lists same-origin, at most every 10 minutes, and writes them to storage.local key bsxEdfinity without changing the page. bsxEdfinity is stored locally only and is removed when the reader is turned off and on sign-out. To test without an account, run node tools/dev-server.js and open /d2l/home?bsxedf=1#/connections or /d2l/home?bsxedf=1#/courses/103/assignments (&bsxedfperm=0 shows the permission prompt, &bsxedfout=1 the signed-out state). All other Firefox permissions are unchanged from 1.4.0; unlimitedStorage is added only to the separate generated Chrome/Edge build and is absent from the Firefox build. Submit the standard Firefox ZIP rather than the -chrome.zip. PRIVACY.md has been added. The Wide Cards experiments in 1.5.21–1.5.23 were reverted in 1.5.24. Account-dependent features require suitable course data; no reviewer credentials are supplied in these notes.
